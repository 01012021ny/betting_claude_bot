### 0.2 Стек (финальный выбор)
| Компонент | Технология | Почему |
|-----------|-----------|--------|
| Язык | Python 3.12 | Богатая экосистема для бот-разработки и AI |
| Бот-фреймворк | aiogram 3.x | Async, быстрый, отличная поддержка Telegram Bot API |
| AI/Анализ | OpenClaw + Claude API | Модульные skills, нативная поддержка Claude |
| БД | PostgreSQL (Supabase) | JSON-поля, надёжность, бесплатный tier |
| ORM | SQLAlchemy 2.0 + asyncpg | Async, миграции через Alembic |
| Кеш | Redis | Горячие данные, rate limiting |
| API спорта | API-Football (основной) + TheSportsDB (fallback) | Покрытие 800+ лиг |
| Хостинг | Railway.app | Простой деплой, бесплатный старт |
| Контейнер | Docker + docker-compose | Локальная разработка и деплой |

## Фаза 1: MVP — "Анализ одного матча" (1-2 недели)

**Цель:** Бот принимает название матча → возвращает AI-анализ с прогнозом.

### 1.1 Telegram бот (aiogram 3)
- [ ] Базовый бот с командами `/start`, `/help`, `/match`
- [ ] Хендлер `/match Реал Мадрид — Барселона` → поиск матча
- [ ] Inline-клавиатура: выбор из найденных матчей
- [ ] Форматирование ответа (markdown): статистика + прогноз
- [ ] Хендлер ошибок и fallback-сообщения

### 1.2 Sports API клиент
- [ ] Обёртка над API-Football: поиск матчей, статистика, составы
- [ ] Эндпоинты: `fixtures/search`, `fixtures/statistics`, `fixtures/lineups`
- [ ] Маппинг JSON → внутренние модели (Match, TeamStats)
- [ ] Кеширование ответов API в Redis (TTL 10 мин для live, 1 час для прошедших)
- [ ] Fallback на TheSportsDB если API-Football недоступен

### 1.3 OpenClaw Skill: `match_analyzer`
- [ ] Установка и настройка OpenClaw (`openclaw onboard`)
- [ ] Создание skill `match_analyzer`:
  - Input: JSON со статистикой матча (составы, форма, H2H, травмы, коэффициенты)
  - Claude prompt: структурированный анализ → прогноз с обоснованием
  - Output: текст прогноза + рекомендации (исход, тотал, обе забьют)
- [ ] Шаблон промпта для Claude:
  ```
  Ты — профессиональный спортивный аналитик.
  Проанализируй матч на основе данных ниже.
  Дай 3-5 рекомендаций по ставкам с КФ > 1.5.
  Для каждой укажи: тип, коэффициент, уверенность (%), обоснование.
  ```
- [ ] Парсинг ответа Claude → структурированный формат для Telegram

### 1.4 Минимальная БД
- [ ] Таблица `users` (telegram_id, username, lang, created_at)
- [ ] Таблица `requests` (user_id, match_query, response, created_at) — логирование
- [ ] Alembic init + первая миграция

### 1.5 Деплой MVP
- [ ] Dockerfile (Python 3.12 + зависимости)
- [ ] docker-compose.yml (бот + PostgreSQL + Redis)
- [ ] .env.example с описанием всех переменных
- [ ] Деплой на Railway.app
- [ ] Базовый health check

**Результат Фазы 1:** Пользователь пишет `/match Барселона — Реал`, получает AI-анализ с прогнозами за <10 секунд.

## Фаза 2: Расширение функций (2-3 недели)

### 2.1 OpenClaw Skill: `express_builder`
- [ ] Skill собирает экспресс-ставки под заданный коэффициент
- [ ] Команда `/express 1000 5.0` → подобрать экспресс с КФ ~5.0 на сумму 1000₽
- [ ] Claude анализирует доступные матчи дня → выбирает самые надёжные исходы
- [ ] Выдаёт 2-3 варианта экспресса (консервативный / умеренный / агрессивный)

### 2.2 Live-матчи
- [ ] Команда `/live` → список текущих live-матчей (API-Football fixtures?live=true)
- [ ] Выбор матча → live-статистика + AI-рекомендация по текущей ситуации
- [ ] OpenClaw Skill `live_monitor`: анализ live-данных, рекомендации по ходу матча

### 2.3 H2H и расширенная статистика
- [ ] Подгрузка head-to-head через API-Football
- [ ] Таблица `h2h_cache` — кеш H2H на 7 дней
- [ ] Форма команд (последние 5-10 матчей)
- [ ] Добавить в промпт `match_analyzer`: H2H, форма, положение в таблице

### 2.4 Статистика пользователя
- [ ] Таблица `user_predictions` (user_id, match_id, prediction, result, profit)
- [ ] Команда `/stats` → история ставок, процент попадания
- [ ] Команда `/roi` → ROI бота за последние 7/30/90 дней
- [ ] OpenClaw Skill `roi_calculator`: агрегация точности по типам ставок

### 2.5 Улучшение UX
- [ ] Inline-режим: `@bot_name Реал Мадрид` → результат прямо в чате
- [ ] Кнопка "Обновить анализ" на live-матчах
- [ ] Кнопка "Добавить в экспресс" → формирование пользовательского экспресса
- [ ] Уведомления: "Матч начался", "Гол!", "Матч завершён — результат ставки"

**Результат Фазы 2:** Полноценный аналитический бот с экспрессами, live и историей.

## Фаза 3: Монетизация (1-2 недели)

### 3.1 Freemium модель
- [ ] Таблица `subscriptions` (user_id, plan, expires_at, payment_id)
- [ ] Free: 1 анализ/день, без экспрессов, без live
- [ ] Premium (199₽/мес): безлимит анализов, экспрессы, live-алерты
- [ ] VIP (999₽/мес): персональные уведомления, приоритет, расширенная аналитика
- [ ] Middleware проверки подписки перед обработкой команд

### 3.2 Оплата
- [ ] Telegram Stars (нативные платежи в Telegram) — основной
- [ ] Yookassa (для РФ, карты/СБП) — альтернативный
- [ ] Команда `/sub` → выбор плана → оплата → активация
- [ ] Автопродление и уведомления об окончании

### 3.3 CPA-партнёрки
- [ ] Таблица `bookmaker_links` (country, bookmaker, cpa_url, cpa_rate)
- [ ] В каждый прогноз — кнопка "Поставить в [БК]" с реферальной ссылкой
- [ ] Гео-определение страны пользователя → подстановка нужной БК
- [ ] Трекинг кликов по CPA-ссылкам

### 3.4 Pay-per-tip
- [ ] Бесплатный анализ — краткий (исход + КФ)
- [ ] Платный анализ (49-99₽) — полный (обоснование, H2H, статистика, 5+ рекомендаций)
- [ ] Telegram Stars для разовых покупок

**Результат Фазы 3:** Три потока дохода: подписка + CPA + разовые покупки.

- [ ] Фильтры: только футбол, только теннис, микс

## Фаза 5: Масштабирование и автоматизация (3-6 недель)

### 5.1 OpenClaw Skill: `odds_tracker`
- [ ] Мониторинг движения коэффициентов (парсинг или API)
- [ ] Оповещения: "КФ на победу Реала упал с 2.10 до 1.80 — лайнер движется"
- [ ] Анализ причин движения (травмы, погода, инсайды)

### 5.2 Push-уведомления
- [ ] Дневной дайджест: "Топ-3 матча дня с высокой уверенностью"
- [ ] Pre-match алерты за 1 час до матчей из избранных лиг
- [ ] Live-алерты: голы, красные карточки, пенальти
- [ ] Настройка уведомлений: `/notifications on|off`, выбор лиг

### 5.3 Cron-задачи
- [ ] Каждые 20 мин: обновление live-матчей
- [ ] Ежедневно 06:00: результаты вчера → обновление ROI
- [ ] Ежедневно 09:00: составы, травмы, погода
- [ ] Еженедельно: пересчёт H2H, очистка устаревших данных
- [ ] APScheduler или Celery Beat

### 5.4 Админ-панель
- [ ] Команды для админа: `/broadcast`, `/user_count`, `/revenue`
- [ ] Мониторинг: кол-во запросов, время ответа, ошибки API
- [ ] Grafana/Prometheus для метрик (опционально)

### 5.5 Инфраструктура
- [ ] Два инстанса: RU-сервер + EU/Global
- [ ] Kubernetes / Docker Swarm при >50k пользователей
- [ ] CDN для статики (если появится веб-интерфейс)
- [ ] Backup БД: ежедневный pg_dump в S3

**Результат Фазы 5:** Автоматизированная система с push-уведомлениями, мониторингом и масштабируемой инфраструктурой.
